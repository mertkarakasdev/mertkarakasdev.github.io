Bu blogu nasıl kurdum

19 Eylül 2026

Bir blog için build adımı, statik site jeneratörü ya da sunucu şart değil. Tailwind'in tarayıcı sürümü ve GitHub Pages ile birkaç HTML dosyası yetiyor.

Kurulum

Repo adını kullanıcı adımla aynı yapıp Settings → Pages bölümünden main dalını seçmek yeterliydi. 

git add -A
git commit -m "Yeni yazı"
git push
Push'tan bir dakika sonra site güncelleniyor.
